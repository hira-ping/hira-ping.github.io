<strong>【問題】</strong><br>
$\alpha, \beta, \gamma$ は相異なる複素数で、

$$ \alpha + \beta + \gamma = \alpha^2 + \beta^2 + \gamma^2 = 0 $$

を満たすとする。このとき、$\alpha, \beta, \gamma$ の表す複素平面上の3点を結んで得られる三角形はどのような三角形か。

<div style="text-align: right; margin-top: 1em;">（2005　京都大学　前期）</div>
</div>

**【解答】**

$\alpha, \beta, \gamma$ を3つの解に持つ3次方程式 $t^3 - pt^2 + qt - r = 0$ を考える。

解と係数の関係より、$p = \alpha + \beta + \gamma$ 。
問題の条件から、
$p = 0$
となる。

解と係数の関係より、$q = \alpha\beta + \beta\gamma + \gamma\alpha$ 。
$$(\alpha + \beta + \gamma)^2 = \alpha^2 + \beta^2 + \gamma^2 + 2(\alpha\beta + \beta\gamma + \gamma\alpha)$$
問題の条件から、$\alpha + \beta + \gamma = 0$、$\alpha^2 + \beta^2 + \gamma^2 = 0$ 。よって、$q = 0$ 。

解と係数の関係より、$r = \alpha\beta\gamma$ 。これは定数としてそのまま $r$ と置く。

したがって、$\alpha, \beta, \gamma$ は
$$t^3 - r = 0$$
という3次方程式の解であることがわかる。

ある複素数 $r$ の 3乗根は、複素平面上で必ず**原点を中心とする正三角形の頂点**となる（※補足）。

（※問題文の条件より $\alpha, \beta, \gamma$ は相異なるため $r \neq 0$ 。）

以上により、$\alpha, \beta, \gamma$ の表す複素平面上の3点を結んで得られる三角形は、原点を中心とする正三角形である。

**【補足】**$t^3 = r$ の解が正三角形になることの証明

ある複素数 $r$ （ただし $r \neq 0$）について、方程式 $t^3 = r$ の 3つの解が複素平面上で正三角形を描くことを示す。

方程式 $t^3 = r$ の解の $1$ つを $t_0$ とする（$r \neq 0$ より $t_0 \neq 0$）。 両辺を $t_0^3$ で割ると、$\left(\frac{t}{t_0}\right)^3 = 1$ となる。ここで、 $z = \frac{t}{t_0}$ とおくと $z^3 = 1$ となり、この解は指数表示を用いて次のように表せる。 $$z = 1, \quad e^{i\frac{2\pi}{3}}, \quad e^{i\frac{4\pi}{3}}$$求めたい元の解は $t = t_0 z$ である。 ここで、$t_0$ を絶対値 $R$、偏角 $\theta$ を用いて $t_0 = R e^{i\theta}$ と表すと、3つの解 $t$ は以下のようになる。 $$t = R e^{i\theta}, \quad R e^{i\left(\theta + \frac{2\pi}{3}\right)}, \quad R e^{i\left(\theta + \frac{4\pi}{3}\right)}$$これは、$z$ が作る原点中心の正三角形を、原点周りに $\theta$ 回転し、$R$ 倍に相似拡大した図形にほかならない。 回転と拡大によって正三角形の形状と中心の位置は保たれるため、$t^3 = r$ の $3$ つの解は複素平面上で必ず原点を中心とする正三角形の頂点となる。

## 考察

### 正 $n$ 角形への一般化

「4個以上ならどうなるか？」という一般化をしたくなる。

4個以上の複素数の場合、1乗の和が $0$、2乗の和が $0$ という2つの条件だけでは、正多角形（正方形など）にはならない。（直感的に条件が足りてない感じはする。）

なぜそうなるのか。4個の場合（$z_1, z_2, z_3, z_4$）で考えてみる。

**4次方程式を考える**

この4つの複素数を解に持つ4次方程式を考える。

$$t^4 - p_1t^3 + p_2t^2 - p_3t + p_4 = 0$$

解と係数の関係を使うと、この4次方程式の係数は次のように決まっていく。

- $p_1 = z_1+z_2+z_3+z_4 = 0$ （問題の条件より $0$）
    
- $p_2$ は2つの積の和であるが、$(z_1+z_2+z_3+z_4)^2 = (z_1^2 +z_2^2 +z_3^2 +z_4^2) + 2p_2$ という関係より、1乗の和も2乗の和も $0$ なので、$p_2 = 0$ となる。

つまり、条件を満たす4つの複素数は、次のような方程式の解であることがわかる。

$$t^4 - p_3t + p_4 = 0$$

**なぜ正方形にならないのか？**

4つの点が複素数平面上で原点を中心とする正方形になるためには、方程式が $t^4 - r = 0$（つまり $p_3 = 0$）という形となる必要がある。

しかし、今回の条件だけでは $p_3$（3つずつの積の和）が $0$ になることまでは強制できない。そのため、$p_3 \neq 0$ となるような方程式を作れば、条件を満たしつつ正方形にならない反例が作れる。

もっとも簡単な反例として、$p_3 = 1, p_4 = 0$ とした方程式を考える。

$$t^4 - t = 0$$

左辺を因数分解すると $t(t^3 - 1) = 0$ となるから、この方程式の4つの解は次のようになる。

- $t = 0$
- $t = 1, \quad e^{i\frac{2\pi}{3}}, \quad e^{i\frac{4\pi}{3}}$ （1の3乗根）

この4つの点（原点と、正三角形の3頂点）は、

- 1乗の和: $0 + 1 + \omega + \omega^2 = 0$
    
- 2乗の和: $0^2 + 1^2 + \omega^2 + \omega^4 = 0$

となり、条件を満たすが、これら結んでも正方形にはならない。

> **正 $n$ 角形を作るための条件**
> 
> 3個のときは1乗と2乗の和が $0$で条件が足りたが、4個の点を正方形にするには「3乗の和も $0$」という追加条件が必要となる。
> 
> 一般化すると、複素数平面上の $n$ 個の点が原点を中心とする正 $n$ 角形を描くためには、
> 
> **「1乗の和、2乗の和、3乗の和、…、$n-1$ 乗の和がすべて $0$ になる」**
> 
> という条件が必要になる。（$t^n - r = 0$ の形が強制されるため。)

すると、次は、基本対称式と冪乗和の関係式が気になる（→ニュートンの関係式）。

そして、ニュートンの関係式の証明は、極限や収束といった解析学の道具を一切使わず、形式的冪級数環という代数の舞台だけで証明を完結できる（→形式的冪級数環）。

### 基本対称式

#### 基本対称式とは

基本対称式とは、$n$ 個の変数から $k$ 個（$1 \le k \le n$）を選んで掛け合わせた積を、考えられるすべての組み合わせについて足し合わせた多項式である。

「対称式（どの2つの変数を入れ替えても値が変わらない多項式）」を構成する最も基礎的な要素であることから、この名が付けられている。

**具体例**

**$n=2$ の場合（変数を $\alpha, \beta$ とする）**

2つの変数から定まる基本対称式は、以下の2つ（$k=1, 2$）である。

- **1つ選ぶ（$k=1$）:** $e_1 = \alpha + \beta$（和）
    
- **2つ選ぶ（$k=2$）:** $e_2 = \alpha\beta$（積）

**$n=3$ の場合（変数を $\alpha, \beta, \gamma$ とする）**

3つの変数から定まる基本対称式は、以下の3つ（$k=1, 2, 3$）である。

- **1つ選ぶ（$k=1$）:** $e_1 = \alpha + \beta + \gamma$
    
- **2つ選ぶ（$k=2$）:** $e_2 = \alpha\beta + \beta\gamma + \gamma\alpha$
    
- **3つ選ぶ（$k=3$）:** $e_3 = \alpha\beta\gamma$

**一般化：$n$ 個の場合（変数を $x_1, x_2, \dots, x_n$ とする）**

基本対称式 $e_k$ は、$n$ 個の変数から $k$ 個を選ぶ組み合わせ（${}_n\mathrm{C}_k$ 通り）の積の総和として定義される。

$$e_k = \sum_{1 \le i_1 < i_2 < \dots < i_k \le n} x_{i_1} x_{i_2} \dots x_{i_k}$$

#### 基本対称式の性質

基本対称式が重要視される理由は、主に以下の2点にある。

##### 1. すべての対称式を基本対称式で表現できる（対称式の基本定理）

任意の対称式は、どれほど複雑であっても必ず基本対称式の加減乗のみで表現できる。

例えば、$n=3$ における平方の和（これも対称式である）は、以下のように基本対称式 $e_1, e_2$ だけで表される。

$$\alpha^2 + \beta^2 + \gamma^2 = (\alpha+\beta+\gamma)^2 - 2(\alpha\beta+\beta\gamma+\gamma\alpha) = e_1^2 - 2e_2$$

このように、基本対称式はあらゆる対称式を構成する最小の基本単位としての役割を持つ。

##### 2. 解と係数の関係の本質である

$n$ 次方程式の解を $x_1, x_2, \dots, x_n$ とすると、これらを解に持つ最高次係数が $1$ の方程式は次のように展開される。

$$(t - x_1)(t - x_2) \dots (t - x_n) = 0$$

$$t^n - e_1 t^{n-1} + e_2 t^{n-2} - \dots + (-1)^n e_n = 0$$

展開した各項の係数は、符号を交互に変えながら $1$ 次から $n$ 次までの基本対称式として現れる。解と係数の関係によって係数が定まる仕組みは、この性質に基づいている。

### 基本対称式と冪乗和の関係式（ニュートンの恒等式）

#### 1. 設定：係数環と形式的冪級数環の定義

まず、代数的な操作を正当化するため、係数環および形式的冪級数環を定義する。
  
**係数環の定義**

$n$ 個の変数 $x_1, \dots, x_n$ を用意し、整数の係数を持つ多項式環 $\mathbb{Z}[x_1, \dots, x_n]$ を構成する。これを係数環 $R$ とする。
  
**形式的冪級数環の導入**

この $R$ を係数に持ち、$t$ を変数とする形式的冪級数環 $R[[t]]$ を考える。以下の計算はすべてこの $R[[t]]$ において行う。

この $R[[t]]$ において、基本となる多項式 $P(t)$ を次のように定義する。

$$P(t) = \prod_{i=1}^{n}(1 - x_i t)$$

この式を展開すると、基本対称式 $e_k$ を係数として以下のように表される（ただし $e_0 = 1$ とする）。

$$P(t) = \sum_{k=0}^{n}(-1)^k e_k t^k = 1 - e_1 t + e_2 t^2 - \dots + (-1)^n e_n t^n$$

#### 2. 逆元と形式的微分の性質

次に、$R[[t]]$ における代数的な性質を2つ確認する。

**性質1：逆元の存在**

$P(t)$ の定数項は $1$ である。形式的冪級数環 $R[[t]]$ において、定数項が乗法逆元を持つ要素は必ず逆元を持つ。したがって、$P(t)^{-1}$ が $R[[t]]$ 内に存在することが保証される。

**性質2：形式的対数微分**

極限を用いず、次数の係数を乗じて次数を1減らす代数的な操作として形式的微分 $P'(t)$ を定義する。さらに、形式的微分と逆元の積として、対数微分を次のように定義する。

$$L(P) := P'(t)P(t)^{-1}$$

ライプニッツ則により、この $L$ は積に対して $L(AB) = L(A) + L(B)$ の関係を満たす。

#### 3. 対数微分の計算

対数微分 $P'(t)P(t)^{-1}$ を2通りの方法で計算する。

**方法A：展開式からの計算**

$P(t) = \sum_{k=0}^{n}(-1)^k e_k t^k$ を形式的に微分すると、以下のようになる。

$$P'(t) = \sum_{k=1}^{n}(-1)^k k e_k t^{k-1}$$

**方法B：因数分解形からの計算**

$P(t) = \prod_{i=1}^{n}(1 - x_i t)$ に対して、対数微分の性質 $L(AB) = L(A) + L(B)$ を適用する。

$$P'(t)P(t)^{-1} = \sum_{i=1}^{n}\left((1 - x_i t)' \cdot (1 - x_i t)^{-1}\right)$$
$$P'(t)P(t)^{-1} = \sum_{i=1}^{n}\frac{-x_i}{1 - x_i t}$$

ここで、右辺の分数は解析的な等比級数ではなく、形式的冪級数環における逆元の展開として、機械的に級数に変換する。

$$\frac{1}{1 - x_i t} = \sum_{m=0}^{\infty}(x_i t)^m$$

これを代入し、和の順序を入れ替える（有限和の交換であるため正当化される）。

$$\sum_{i=1}^{n}-x_i\left(\sum_{m=0}^{\infty}(x_i t)^m\right) = -\sum_{m=1}^{\infty}\left(\sum_{i=1}^{n}x_i^m\right)t^{m-1}$$

内側の和 $\sum_{i=1}^{n}x_i^m$ は冪和対称式 $p_m$ の定義そのものである。したがって、以下のように整理される。

$$P'(t)P(t)^{-1} = -\sum_{m=1}^{\infty}p_m t^{m-1}$$

両辺に $P(t)$ を乗じると、次式を得る。

$$P'(t) = P(t)\left(-\sum_{m=1}^{\infty}p_m t^{m-1}\right)$$

#### 4. 係数比較

方法Aと方法Bの結果を等号で結ぶ。

$$\sum_{k=1}^{n}(-1)^k k e_k t^{k-1} = \left(\sum_{j=0}^{n}(-1)^j e_j t^j\right)\left(-\sum_{m=1}^{\infty}p_m t^{m-1}\right)$$

これは形式的冪級数環 $R[[t]]$ における等式であるため、両辺の $t^{k-1}$ の係数は完全に一致する。それぞれの係数を抽出する。

- **左辺の係数:** $(-1)^k k e_k$
    
- **右辺の係数:** 右辺の積を展開したとき、$t^j \cdot t^{m-1} = t^{k-1}$ となるのは $m = k - j$ のときである。これを $j$ について足し合わせると、$-\sum_{j=0}^{k-1}(-1)^j e_j p_{k-j}$ となる。

よって、以下の等式が導かれる。

$$(-1)^k k e_k = -\sum_{j=0}^{k-1}(-1)^j e_j p_{k-j}$$

両辺に $(-1)^k$ を掛け、符号を整理すると、ニュートンの恒等式が得られる。

  
$$k e_k = \sum_{j=1}^{k}(-1)^{j-1} e_{k-j} p_j$$
  
> この証明は、極限や収束といった解析的な概念に依存せず、形式的冪級数環における代数的な操作のみによって完結している。

#### 具体例

**（1）冪和対称式 $p_k$ を求める形**

与えられた基本対称式から、変数の累乗の和を計算する際によく用いられる漸化式の形である。

$$p_1 = e_1$$

$$p_2 = e_1 p_1 - 2 e_2$$

$$p_3 = e_1 p_2 - e_2 p_1 + 3 e_3$$

$$p_4 = e_1 p_3 - e_2 p_2 + e_3 p_1 - 4 e_4$$

右辺に得られた $p_j$ の結果を順次代入していくことで、すべて基本対称式 $e_k$ だけで表す形に展開できる。

$$p_1 = e_1$$

$$p_2 = e_1^2 - 2 e_2$$

$$p_3 = e_1^3 - 3 e_1 e_2 + 3 e_3$$

$$p_4 = e_1^4 - 4 e_1^2 e_2 + 4 e_1 e_3 + 2 e_2^2 - 4 e_4$$

**（2）基本対称式 $e_k$ を求める形**

逆に、冪和対称式 $p_k$ の値がわかっている状態から、基本対称式 $e_k$ を順に特定するための形である。先の式を $e_k$ について解いたものに等しい。

$$e_1 = p_1$$

$$e_2 = \frac{1}{2}(e_1 p_1 - p_2)$$

$$e_3 = \frac{1}{3}(e_2 p_1 - e_1 p_2 + p_3)$$

$$e_4 = \frac{1}{4}(e_3 p_1 - e_2 p_2 + e_1 p_3 - p_4)$$

こちらも同様に代入を繰り返すことで、すべて冪和対称式 $p_k$ だけで表す形に展開できる。

$$e_1 = p_1$$

$$e_2 = \frac{1}{2}(p_1^2 - p_2)$$

$$e_3 = \frac{1}{6}(p_1^3 - 3 p_1 p_2 + 2 p_3)$$

$$e_4 = \frac{1}{24}(p_1^4 - 6 p_1^2 p_2 + 8 p_1 p_3 + 3 p_2^2 - 6 p_4)$$
