$e^x$、$\sin x$、$\cos x$、$\log x$ を厳密に定義する。$e^x$、$\sin x$、$\cos x$ はべき級数として定義し、$\log x$ は $1/t$ の積分として定義する。そして、べき級数で定義した $e^x$ と積分で定義した $\log x$ が互いに逆関数の関係にあることを確認する。

## 指数関数

### 定義：指数関数

$$e^x := \sum_{n=0}^{\infty} \frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \cdots$$

**収束半径：** 比率判定法を適用する。

$$\frac{|x|^{n+1}/(n+1)!}{|x|^n/n!} = \frac{|x|}{n+1} \to 0 < 1$$

すべての $x \in \mathbb{R}$ に対して収束するから $R = \infty$。

**微分：** べき級数の微分可能性より、

$$(e^x)' = \sum_{n=1}^{\infty} \frac{n x^{n-1}}{n!} = \sum_{n=1}^{\infty} \frac{x^{n-1}}{(n-1)!} = \sum_{m=0}^{\infty} \frac{x^m}{m!} = e^x$$

指数関数は微分しても自分自身に戻る。この性質は指数関数の本質である。

**$e$ の定義：** $e := e^1 = \displaystyle\sum_{n=0}^{\infty} \frac{1}{n!}$

## 三角関数

### 定義：三角関数

$$\sin x := \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n+1}}{(2n+1)!} = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots$$

$$\cos x := \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n}}{(2n)!} = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots$$

**収束半径：** 指数関数と同様の計算により、どちらも $R = \infty$。

**微分：** べき級数の微分可能性より、

$$(\sin x)' = \sum_{n=0}^{\infty} \frac{(-1)^n (2n+1) x^{2n}}{(2n+1)!} = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n}}{(2n)!} = \cos x$$

$$(\cos x)' = \sum_{n=0}^{\infty} \frac{(-1)^n (2n) x^{2n-1}}{(2n)!} = \sum_{n=1}^{\infty} \frac{(-1)^n x^{2n-1}}{(2n-1)!} = -\sum_{m=0}^{\infty} \frac{(-1)^m x^{2m+1}}{(2m+1)!} = -\sin x$$

### オイラーの公式

複素数の範囲でべき級数を考えると（係数の計算は同様に成り立つ）、

$$e^{ix} = \cos x + i\sin x$$

が成り立つ。

> **円周率 $\pi$ の定義：** $\cos x$ の最小正の零点として $\pi/2$ を解析的に定義する。

## 対数関数

### 定義：対数関数

$$\log x := \int_1^x \frac{1}{t}\,dt \qquad (x > 0)$$

$1/t$ は $(0, \infty)$ 上で連続だから可積分であり、この定義は正当化される。

### 基本性質

**微分：** 微積分学の基本定理（第1形式）より直ちに

$$(\log x)' = \frac{1}{x}$$

**単調性：** $x > 0$ で $(\log x)' = 1/x > 0$ だから $\log x$ は狭義単調増加。

**符号：** $\log 1 = \int_1^1 1/t\,dt = 0$。$x > 1$ で $\log x > 0$、$0 < x < 1$ で $\log x < 0$。

**加法性：** $x, y > 0$ に対して $\log(xy) = \log x + \log y$。

**証明.** $g(x) := \log(xy) - \log x$ とおく。$g'(x) = y/(xy) - 1/x = 0$ だから $g$ は定数。$g(1) = \log y$ より $g(x) = \log y$ $\square$

## 指数関数と対数関数の関係

$\log x$ は狭義単調増加で連続であるため、逆関数が存在する。この逆関数は、本ノートでべき級数として定義した指数関数 $e^x$ と一致する。

**証明.** 合成関数 $h(x) = \log(e^x)$ を微分すると、連鎖律と $(e^x)' = e^x$ より

$$h'(x) = \frac{1}{e^x} \cdot (e^x)' = \frac{1}{e^x} \cdot e^x = 1$$

したがって $h(x) = x + C$（定数）となる。$x=0$ を代入すると $h(0) = \log(e^0) = \log 1 = 0$ より $C=0$。ゆえに $\log(e^x) = x$ が成り立ち、$e^x$ が $\log x$ の逆関数であることが示された。$\square$

> **二つのアプローチについて：** $e^x$ はべき級数として、$\log x$ は積分として定義した。$\log x$ は $e^x$ の逆関数として定義することもできるが、積分による定義の方が $(\log x)' = 1/x$ という性質を出発点として自然に組み上がる。二つのアプローチは同じ対象を異なる入口から定義しており、最終的に同じ関数を与える。
