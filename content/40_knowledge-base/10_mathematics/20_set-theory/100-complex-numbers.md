$\mathbb{R}$ は完備順序体として完成したが、一つの限界がある。多項式 $x^2 + 1 = 0$ の解が $\mathbb{R}$ に存在しない。本ノートでは直積 $\mathbb{R} \times \mathbb{R}$ に適切な演算を定めることで複素数体 $\mathbb{C}$ を構成し、体の公理を確認する。$\mathbb{Q} \to \mathbb{R}$ が位相的な構成（完備化）であったのに対し、$\mathbb{R} \to \mathbb{C}$ は代数的な構成（根の付加）である。

## ℝ の限界と拡張の動機

$\mathbb{R}$ は体・全順序・完備性（上限性質）を満たす。しかし次の多項式は実数の根を持たない。

> **確認：$x^2 + 1 = 0$ は $\mathbb{R}$ に解を持たない。** 任意の $x \in \mathbb{R}$ に対して $x^2 \geq 0$ だから $x^2 + 1 \geq 1 > 0$。よって $x^2 + 1 \neq 0$。$\square$

この $x^2 + 1 = 0$ の根を追加することが本ノートの目標である。$\mathbb{Q} \to \mathbb{R}$ では有理数直線の穴（極限値の不存在）を埋めた。$\mathbb{R} \to \mathbb{C}$ では多項式の根の不在を補う。どちらも欠如を補う操作だが、その性格は全く異なる。

## 集合論的構成

### 定義

$$\mathbb{C} := \mathbb{R} \times \mathbb{R}$$

とし、加法と乗法を次で定める。

**加法：**

$$(a, b) + (c, d) := (a + c,\, b + d)$$

**乗法：**

$$(a, b) \cdot (c, d) := (ac - bd,\, ad + bc)$$

加法の定義は $\mathbb{R}^2$ のベクトル和そのものである。乗法の定義は $(a + bi)(c + di) = (ac - bd) + (ad + bc)i$ という形式的な計算を先取りしたものであり、$i^2 = -1$ が成り立つよう設計されている。集合論的には、この計算規則を定義として採用することが出発点である。

### 乗法の設計原理

乗法の $(ac-bd, ad+bc)$ という形は、$i := (0,1)$ が $i^2 = -1$ を満たすよう逆算すると一意に定まる。実際、

$$(0, 1) \cdot (0, 1) = (0 \cdot 0 - 1 \cdot 1,\; 0 \cdot 1 + 1 \cdot 0) = (-1, 0)$$

であり、$(1, 0)$ を実数の $1$ と同一視すれば $i^2 = -1$ となる。

## 体の公理の確認

$(\mathbb{C}, +, \cdot)$ が体をなすことを確認する。

### 加法

- **結合律：** $((a,b) + (c,d)) + (e,f) = (a+c+e,\, b+d+f) = (a,b) + ((c,d) + (e,f))$。$\checkmark$
- **可換律：** $(a+c,\, b+d) = (c+a,\, d+b)$。$\checkmark$
- **単位元：** $0_\mathbb{C} := (0, 0)$。$(a,b) + (0,0) = (a,b)$。$\checkmark$
- **逆元：** $-(a,b) := (-a, -b)$。$(a,b) + (-a,-b) = (0,0)$。$\checkmark$

よって $(\mathbb{C}, +)$ は可換群。

### 乗法

- **結合律：** $((a,b)(c,d))(e,f) = (ace - bde - adf - bcf,\; \ldots) = (a,b)((c,d)(e,f))$。（成分計算により確認）$\checkmark$
- **可換律：** $(ac - bd,\; ad + bc) = (ca - db,\; cb + da)$。$\checkmark$
- **単位元：** $1_\mathbb{C} := (1, 0)$。$(a,b)(1,0) = (a \cdot 1 - b \cdot 0,\; a \cdot 0 + b \cdot 1) = (a, b)$。$\checkmark$
- **逆元（$0_\mathbb{C}$ 以外）：** $(a,b) \neq (0,0)$ ならば $a^2 + b^2 > 0$。

$$\left(\frac{a}{a^2+b^2},\; \frac{-b}{a^2+b^2}\right)$$

が逆元であることを確認する：

$$(a,b) \cdot \left(\frac{a}{a^2+b^2}, \frac{-b}{a^2+b^2}\right) = \left(\frac{a^2+b^2}{a^2+b^2},\; \frac{-ab+ab}{a^2+b^2}\right) = (1, 0)$$

$\checkmark$

よって $(\mathbb{C} \setminus \{0_\mathbb{C}\}, \cdot)$ は可換群。

### 分配律

$$(a,b)\bigl((c,d)+(e,f)\bigr) = (a,b)(c+e,\, d+f)$$

$$= \bigl(a(c+e)-b(d+f),\; a(d+f)+b(c+e)\bigr)$$

$$= (ac-bd,\; ad+bc) + (ae-bf,\; af+be) = (a,b)(c,d) + (a,b)(e,f) \quad\checkmark$$

よって $(\mathbb{C}, +, \cdot)$ は**体**である。$\square$

> **$\mathbb{C}$ は全順序体でない。**
>仮に全順序が入るとすると、$i > 0$ か $i < 0$ かのどちらかである。$i > 0$ ならば $i^2 = -1 > 0$ となり $1 + 1 > 1 > 0$ に矛盾（$-1 < 0$ のはず）。$i < 0$ ならば $-i > 0$ で $(-i)^2 = -1 > 0$ も同様に矛盾。よって $\mathbb{C}$ には全順序体の構造を入れられない。$\square$

## 虚数単位

$$i := (0, 1)$$

と定める。前節で確認したとおり、

$$i^2 = (0,1) \cdot (0,1) = (-1, 0)$$

$\mathbb{R}$ の埋め込み（次節）のもとで $(1,0)$ を $1$ と同一視すれば、$i^2 = -1$ が成り立つ。

$i$ は方程式 $x^2 + 1 = 0$ の解の一つであり、$-i = (0,-1)$ がもう一つの解である。

## ℝ の埋め込み

写像 $\iota: \mathbb{R} \to \mathbb{C}$ を $\iota(r) := (r, 0)$ で定める。

**命題：** $\iota$ は体の単射準同型（埋め込み）である。

**証明.**
- **加法：** $\iota(r+s) = (r+s, 0) = (r,0) + (s,0) = \iota(r) + \iota(s)$。$\checkmark$
- **乗法：** $\iota(rs) = (rs, 0)$。$(r,0)(s,0) = (rs - 0,\; r \cdot 0 + 0 \cdot s) = (rs, 0)$。$\checkmark$
- **単位元の保存：** $\iota(1) = (1, 0) = 1_\mathbb{C}$。$\checkmark$
- **単射性：** $\iota(r) = \iota(s) \Rightarrow (r,0) = (s,0) \Rightarrow r = s$。$\checkmark$ $\square$

以降、$r \in \mathbb{R}$ と $(r, 0) \in \mathbb{C}$ を同一視する。特に $1 = (1,0)$、$-1 = (-1,0)$。

## $a + bi$ 表記

任意の $(a, b) \in \mathbb{C}$ に対して、

$$(a, b) = (a, 0) + (0, b) = (a, 0) + (b, 0) \cdot (0, 1) = a \cdot 1_\mathbb{C} + b \cdot i$$

よって $(a, b) = a + bi$ と書ける。$a$ を**実部**、$b$ を**虚部**といい、

$$a = \mathrm{Re}(z), \qquad b = \mathrm{Im}(z)$$

と書く。この表記のもとで演算は次のように整理される。

$$(a + bi) + (c + di) = (a+c) + (b+d)i$$

$$(a + bi)(c + di) = (ac - bd) + (ad + bc)i$$

## 複素共役と絶対値

$z = a + bi \in \mathbb{C}$ に対して以下を定める。

**複素共役：**

$$\bar{z} := a - bi$$

**絶対値：**

$$|z| := \sqrt{a^2 + b^2}$$

### 基本性質

$$z\bar{z} = (a+bi)(a-bi) = a^2 + b^2 = |z|^2$$

$$ |z| = 0 \iff z = 0 $$

$$ \overline{z + w} = \bar{z} + \bar{w}，\overline{zw} = \bar{z}\bar{w} $$

$$ |zw| = |z||w| $$

### 逆元の再表示

$ z \neq 0 $ のとき、
$ z \bar{z} = |z|^2 > 0 $ より、

$$z^{-1} = \frac{\bar{z}}{|z|^2} = \frac{a - bi}{a^2 + b^2}$$

これは分母に共役を掛けて実数化する操作に対応する。

### 三角不等式

$$|z + w| \leq |z| + |w|$$

**証明.**

$$|z + w|^2 = (z+w)\overline{(z+w)} = (z+w)(\bar{z}+\bar{w}) = |z|^2 + (z\bar{w} + \bar{z}w) + |w|^2$$

$$ z\bar{w} + \bar{z}w = 2\,\mathrm{Re}(z\bar{w}) \leq 2|z\bar{w}| = 2|z||w| $$
だから、

$$|z + w|^2 \leq |z|^2 + 2|z||w| + |w|^2 = (|z| + |w|)^2$$

よって、
$|z + w| \leq |z| + |w|$。
$\square$

> $\mathbb{C}$ に絶対値 $|\cdot|$ を距離として導入することで、
>$\mathbb{C}$ は距離空間（さらには $\mathbb{R}^2$ と同相の完備距離空間）になる。
>複素解析はこの距離構造の上に構築される。

## 代数的閉性

$\mathbb{C}$ の最も重要な性質は**代数的閉体**であることである。

**定理（代数学の基本定理）：** $n \geq 1$ 次の多項式 $f \in \mathbb{C}[x]$ は $\mathbb{C}$ に少なくとも一つの根を持つ。

証明は複素解析（リウヴィルの定理：有界正則関数は定数）または代数的位相幾何学（$\pi_1(\mathbb{C}^*) \cong \mathbb{Z}$）を用いる（らしい）。本ノートでは（不本意ながらも）一旦その存在を認め、意義のみ確認する。

**帰結：** $f \in \mathbb{C}[x]$ が $n$ 次多項式ならば、$\mathbb{C}$ の根をちょうど $n$ 個（重複度込み）持つ：

$$f(x) = c(x - \alpha_1)(x - \alpha_2) \cdots (x - \alpha_n), \qquad c, \alpha_1, \ldots, \alpha_n \in \mathbb{C}$$

>$\mathbb{Q} \to \mathbb{R}$ の構成は、有理数の穴を埋めるため無限の操作を必要とした。一方 $\mathbb{R} \to \mathbb{C}$ は $i$ という一元を追加するだけで代数的閉体になる。これは非自明であり、代数学の基本定理の核心である。

## 数体系の完成

```
空集合の公理・無限の公理・分出公理図式
        ↓
        ω（自然数）
        ↓ 差による同値類（代数的構成）
        ℤ（整数）　← 加法の逆元を補完
        ↓ 比による同値類（代数的構成）
        ℚ（有理数）← 乗法の逆元を補完；体・全順序、しかし完備性を欠く
        ↓ デデキント切断 or コーシー列（位相的構成）
        ℝ（実数）　← 完備性を補完；体・全順序・完備
        ↓ 直積 ℝ × ℝ による構成（代数的構成）
        ℂ（複素数）← 代数的閉性を補完；体・代数閉（ただし全順序なし）
```

各矢印の性格を振り返る：

- $\omega \to \mathbb{Z} \to \mathbb{Q}$：**代数的構成**: 不足した演算（減法・除法）を同値類で補う。
- $\mathbb{Q} \to \mathbb{R}$：**位相的構成**: 有理数列の近づく先を新たに付け加える（完備化）。
- $\mathbb{R} \to \mathbb{C}$：**代数的構成**: 多項式 $x^2 + 1$ の根を直積で補完する。

$\mathbb{C}$ は代数閉体であり、多項式の根が存在しないという欠如がない。数体系の集合論的構成はここで一段落する。
代数学や解析学では $\mathbb{R}$（および $\mathbb{C}$）を所与として展開する。
