整数・有理数の構成では、同じ差や同じ比を表すペアを一つのものとして扱う。この同じとみなすという操作を集合論で厳密に定式化するのが同値関係・同値類・商集合である。本ノートではこれらを丁寧に展開し、特に well-definedness（演算が代表元の選び方によらないこと）の意味を明確にする。

## 二項関係（再掲）

集合 $A$ 上の**二項関係**とは、直積 $A \times A$ の部分集合 $R \subseteq A \times A$ のことである。$\langle a, b \rangle \in R$ のとき、$a \mathrel{R} b$ と書く。

> **例:**
> - $A = \mathbb{Z}$、$R = \\{\langle a,b \rangle \mid a \leq b\\}$：通常の順序関係
> - $A = \mathbb{Z}$、$R = \\{\langle a,b \rangle \mid a \equiv b \pmod{2}\\}$：偶奇の一致
{: .prompt-info }

## 同値関係

集合 $A$ 上の二項関係 $R$ が以下の3条件をすべて満たすとき、$R$ を $A$ 上の**同値関係**という。同値関係を表す関係記号としては、慣習的に $R$ の代わりに $\sim$ や $\equiv$ がよく用いられる（以下、$a \mathrel{R} b$ を $a \sim b$ と書く）。

| 条件 | 名称 | 意味 |
| :--- | :--- | :--- |
| $\forall a \in A,\; a \sim a$ | 反射律 | すべての元は自分自身と同値 |
| $a \sim b \Rightarrow b \sim a$ | 対称律 | 同値は双方向 |
| $a \sim b \land b \sim c \Rightarrow a \sim c$ | 推移律 | 同値は連鎖する |

### 具体例

**例1：整数の合同（時計の算術）**

$\mathbb{Z}$ 上の関係 $a \sim b \iff 2 \mid (a - b)$（$a$ と $b$ の差が偶数）を考える。

- *反射律:* $a - a = 0 = 2 \cdot 0$。$\checkmark$
- *対称律:* $2 \mid (a-b) \Rightarrow a - b = 2k \Rightarrow b - a = 2(-k)$。$\checkmark$
- *推移律:* $2 \mid (a-b)$ かつ $2 \mid (b-c)$ ならば $a - c = (a-b)+(b-c)$ も $2$ の倍数。$\checkmark$

よってこれは同値関係。直観的には、偶数どうし、奇数どうしを同じとみなしている。

**例2：整数の構成で使う同値関係**

$\omega \times \omega$ 上の関係 $(a,b) \sim (c,d) \iff a + d = b + c$ を考える（$a - b = c - d$ の言い換え）。

- **反射律:** $a + b = b + a$。$\checkmark$
- **対称律:** $a + d = b + c \Rightarrow c + b = d + a$。$\checkmark$
- **推移律:** $a + d = b + c$ かつ $c + f = d + e$ を仮定する。辺々足すと $a + d + c + f = b + c + d + e$。$c + d$ を消去して $a + f = b + e$。$\checkmark$

**例3：同値関係でない例**

$\mathbb{Z}$ 上の関係 $a \sim b \iff a < b$ は反射律（$a < a$ は偽）も対称律（$a < b$ かつ $b < a$ は両立しない）も満たさないから同値関係でない。

## 同値類

$\sim$ を集合 $A$ 上の同値関係とする。元 $a \in A$ の**同値類**を

$$[a] := \{x \in A \mid x \sim a\}$$

と定める。$[a]$ は$a$ と同値なものすべての集まりである。このとき、同値類 $[a]$ の基準として表記に用いた元 $a$ を、この同値類の**代表元**という。

> **使用公理：分出公理図式**
> ZFCの分出公理図式において、母集合を $A$、条件式 $\phi(x)$ を $x \sim a$ （すなわち $\langle x, a \rangle \in {\sim}$）とすることで、この同値類 $[a]$ が確かに一つの「集合」として切り出せることが保証される。

### 同値類の基本性質

同値類には以下の重要な性質がある。

**性質1:** $a \sim b \iff [a] = [b]$

**証明.** $(\Rightarrow)$ $a \sim b$ を仮定する。$x \in [a]$ とすると $x \sim a$。推移律より $x \sim b$、すなわち $x \in [b]$。よって $[a] \subseteq [b]$。対称律より $b \sim a$ だから同様に $[b] \subseteq [a]$。ゆえに $[a] = [b]$。

$(\Leftarrow)$ $[a] = [b]$ を仮定する。反射律より $a \in [a] = [b]$、すなわち $a \sim b$。$\square$

**性質2:** $[a] \neq [b] \Rightarrow [a] \cap [b] = \emptyset$（異なる同値類は交わらない）

**証明.** 対偶を示す。$x \in [a] \cap [b]$ とすると $x \sim a$ かつ $x \sim b$。対称律より $a \sim x$、推移律より $a \sim b$。性質1より $[a] = [b]$。$\square$

### 直観的イメージ

性質1と性質2を合わせると：**同値類は代表元の選び方によらず一意に決まり、異なる同値類は重ならない。**

$a$ と $b$ が同値であれば、どちらを代表元として選んでも同じ同値類を指す。これが後で演算の well-definedness を保証する根拠になる。

> **例（整数の合同）:** $[0] = \\{\ldots, -4, -2, 0, 2, 4, \ldots\\}$（偶数全体）、$[1] = \\{\ldots, -3, -1, 1, 3, 5, \ldots\\}$（奇数全体）。$[0]$ と $[1]$ は交わらず、合わせて $\mathbb{Z}$ 全体を覆う。

## 商集合

$\sim$ を $A$ 上の同値関係とする。$A$ の全同値類を要素とする集合を**商集合**といい、

$$A / {\sim} \; := \{[a] \mid a \in A\}$$

と定める。

> **注意:** $A/{\sim}$ の要素は $A$ の元ではなく、$A$ の部分集合（同値類）である。「元の集合を同値類でまとめ直した集合」と読むとよい。

> **使用公理：置換公理図式**
> $\{[a] \mid a \in A\}$ という同値類の集まりが集合として存在することは、実は自明ではない。ここで**置換公理**が決定的な役割を果たす。各 $a \in A$ に対して同値類 $[a]$ を対応させる関数的関係 $F(a) = [a]$ を考える。置換公理は、集合（ここでは $A$）の像はまた集合であることを保証するため、その像である商集合 $A/{\sim}$ が厳密に集合として存在することが言える。

### 具体例

**例1（偶奇）:** $\mathbb{Z}/{\sim} = \\{[0], [1]\\}$。整数全体が偶数の同値類と奇数の同値類の2つに整理される。

**例2（整数の構成）:** $(\omega \times \omega)/{\sim}$ では、例えば：

$$[(3,1)] = \{(x,y) \in \omega \times \omega \mid x + 1 = y + 3\} = \{(2,0),(3,1),(4,2),\ldots\}$$

これが整数 $2$（$= 3 - 1$）を表す同値類である。

## 分割との対応

同値関係と集合の**分割**は一対一に対応する。

**分割の定義:** $A$ の部分集合族 $\{A_\lambda\}_{\lambda \in \Lambda}$ が $A$ の分割であるとは、以下を満たすことをいう。
1. $A_\lambda \neq \emptyset$（各部分は空でない）
2. $\lambda \neq \mu \Rightarrow A_\lambda \cap A_\mu = \emptyset$（互いに交わらない）
3. $\bigcup_{\lambda \in \Lambda} A_\lambda = A$（合わせて全体を覆う）

**対応:** 同値関係 $\sim$ から商集合 $A/{\sim}$ を作ると分割が得られる。逆に分割 $\{A_\lambda\}$ から、「同じ $A_\lambda$ に属する $\iff$ 同値」とすれば同値関係が得られる。この対応は互いに逆であり、**同値関係と分割は一対一対応する。**

> **直観:** 同値関係とは集合を重なりなく仕切る方法といえる。

## Well-definedness：代表元によらないことの確認

商集合 $A/{\sim}$ 上に演算を定めるとき、代表元を通じて定義するのが標準的な方法である。

$$[a] \star [b] := [a \ast b]$$

しかしこの定義が意味をなすためには、**右辺が代表元の選び方によらない**ことを確認しなければならない。これを **well-definedness（適切な定義であること）の確認**という。

### なぜ確認が必要か

$[a] = [a']$ かつ $[b] = [b']$ であるとき（すなわち $a \sim a'$ かつ $b \sim b'$ のとき）、

$$[a \ast b] = [a' \ast b']$$

が成り立たなければ、演算の値が代表元の選び方によって変わってしまい、$[a] \star [b]$ は同値類上の演算として定義できない。

### 具体例：整数の加法の well-definedness

$(\omega \times \omega)/{\sim}$ 上の加法を $[(a,b)] + [(c,d)] := [(a+c, b+d)]$ で定める。

$[(a,b)] = [(a',b')]$ すなわち $a + b' = b + a'$、および $[(c,d)] = [(c',d')]$ すなわち $c + d' = d + c'$ を仮定する。

$(a+c) + (b'+d') = (a+b') + (c+d') = (b+a') + (d+c') = (b+d) + (a'+c')$

よって $(a+c, b+d) \sim (a'+c', b'+d')$、すなわち $[(a+c,b+d)] = [(a'+c',b'+d')]$。$\square$

## 標準射影

商集合への自然な写像として**標準射影**がある。

$$\pi: A \to A/{\sim}, \qquad \pi(a) := [a]$$

$\pi$ は全射である（任意の同値類 $[a]$ は $\pi(a)$ として得られる）。また $\pi(a) = \pi(b) \iff a \sim b$ が成り立ち、$\pi$ は同値関係の情報をそのまま写像として表現している。

商集合上の演算 $\star$ が well-defined であることは、$\pi$ を通じて$A$ 上の演算 $\ast$ が $A/{\sim}$ 上に降りてくると言い換えることができる。
